# Flam × Instagram · Interactive Flicks

The Flam × Instagram pitch deck as one self-contained static page (`index.html`).

## Deploy on Vercel
1. Import this repository in Vercel (Add New → Project).
2. Framework preset: **Other**. No build command, output directory = root.
3. Deploy.

## Present
- Arrow keys or the on-screen buttons move between slides; **F** toggles full screen.
- The live Flicks, the benchmark and the Instagram demo load from the web, so present online.
